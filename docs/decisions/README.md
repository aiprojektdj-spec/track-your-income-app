# Architecture decisions

One file per decision: `NNNN-short-title.md`, numbered in order. Copy `0000-adr-template.md` to start.

Rules:
- Decisions are never deleted. When one changes, write a new ADR and mark the old one *superseded*.
- Agents must follow accepted ADRs. Disagreement is expressed as a new *proposed* ADR.
- If a decision can be checked automatically (lint rule, test, schema), link the check in the ADR.
